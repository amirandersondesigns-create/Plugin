ABOUT THE PLUGIN
---------------------------------------------------------------------------
 Product:    Amir Anderson Project Organizer
 Version:    1.5.2
 Made by:    Amir Anderson
 Price:      Free
 Works with: Adobe After Effects 2022 (22.0) or later, macOS or Windows
 Contact:    https://www.linkedin.com/in/amiranderson

Project Organizer is a panel for Adobe After Effects that gets a project
ready to hand off: it collects every file the project uses into a standard
folder structure (AE, AI, AUDIO, C4D, DELIVERABLES, FOOTAGE, PS, SOURCE
IMAGES and more), relinks the project, files every asset into matching
Project-panel folders, saves the project and writes a handoff report.

What's included in the download:
 - Amir_Anderson_Project_Organizer.zxp     the plugin (install this one)
 - LICENSE.txt                             this file

Inside the panel, the same terms are summarized under Help > About > Terms.
