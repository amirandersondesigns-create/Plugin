Welcome to the Amir Anderson Project Organizer

Before you hand off a job, it gathers every file your project uses into one clean folder structure — AE, AI, PS, AUDIO, FOOTAGE, SOURCE IMAGES — so nothing is ever missing.

1 Analyze

See where every file will go, what's already in place and what's missing. Nothing is changed until you say so.

2 Organize & Save

Files are copied in (originals are never moved), the project is relinked, every asset is filed into matching Project-panel folders, and it's saved into AE/ with a handoff report.

How it works

1
Locate. The organizer works out the job folder from where the project is saved: inside an AE folder → the folder above it; next to FOOTAGE, PS… → that folder; anywhere else → a new folder (named in "Folder name") next to the .aep. Change… picks any folder, Auto goes back.
2
Analyze. Shows where every file will go, what's already in place and what's missing. Nothing is changed. Missing files are listed first in red — relink those in After Effects before you hand off.
3
Organize & Save. Builds the folders, copies each file in (originals are never moved or deleted), relinks the project, files every asset into matching folders in the Project panel, saves it into AE/ and writes _HANDOFF_REPORT.txt. The relink is one undo step.

Layered Photoshop / Illustrator files

Files imported as a composition keep every layer when relinked. If a layer can't be matched it's relinked flattened and flagged in the report as "CHECK".

Project panel

Organize & Save also files every asset into matching folders inside the After Effects project — FOOTAGE, AUDIO, SOURCE IMAGES › PNG, PS and so on. Folders you already have are reused, never duplicated (names match regardless of capitals), items already in the right folder stay put, and layered Photoshop/Illustrator imports move with their "Layers" folder.

Fonts

Installed font files are copied into FONTS/. Adobe Fonts can't be copied — they're listed in the report so the next person can activate them in Creative Cloud. Check your font licences before sending fonts outside your organization.
