Motion Project Organizer — Help

When to use it

At the end of a job, before you hand it off. It gathers every file your project uses into one tidy folder, relinks the project to those copies and saves the .aep inside it — so whoever opens it next has everything, nothing offline.

1 · Project folder

The organizer works out where the job lives from where the project is saved:

• Saved inside an AE folder → the folder above it is the project folder.
• Saved next to FOOTAGE, PS, etc. → that folder is used.
• Anywhere else → a new folder (named in "Folder name") is made next to the .aep.
Click Change… to pick any folder instead, Auto to go back.

2 · Analyze

Shows where every file will go, what's already in place and what's missing. Nothing is changed. Missing files are listed first in red — relink those in After Effects before you hand off, because there's nothing to copy.

3 · Organize & Save

Creates the folder structure, copies each file into it (originals are never moved or deleted), relinks the project to the copies, saves the project into AE/ and writes _HANDOFF_REPORT.txt. The relink is one undo step.

Where files go

AE: the project (ARCHIVE for old versions) · AI: .ai .eps .svg · PS: .psd .psb · AUDIO: music and nat sound, with VO and SFX sorted by file name · C4D: .c4d, MODELS: .fbx .obj …, RENDER: .exr and 3D render passes · DATA: .csv .json stats · ESP_EarthStudioPro: anything from a Google Earth Studio folder · FOOTAGE: video and image sequences, STOCK: Getty / Shutterstock / AP … · REFERENCE: files named ref, mockup, styleframe · SOURCE IMAGES: HEADSHOTS, LOGOS, STOCK, then PNG / JPG / PDF / TIFF / OTHER · FONTS: fonts.

DELIVERABLES also gets REVIEW, SOCIAL and THUMBNAILS folders for your own exports.

Change any of this with Options → Edit folder rules…

Layered Photoshop / Illustrator files

Files imported as a composition keep every layer when relinked. If a layer can't be matched it's relinked flattened and flagged in the report as "CHECK".

Fonts

Installed font files are copied into FONTS/. Adobe Fonts can't be copied — they're listed in the report so the next person can activate them in Creative Cloud. Check your font licences before sending fonts outside your organization.
