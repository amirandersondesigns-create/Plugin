Motion Spell Checker — Help

Scanning

Pick a scope (Active Comp, Entire Project, or Selected Layers) and click Scan. The checker reads layer names, text layers, marker comments, string effect parameters, and quoted string literals inside expressions.

Settings drawer

Open it with the gear icon. "Ignore hidden" / "Ignore locked" / "Selected only" restrict which layers are scanned. "Force highlight visibility" and "Disable global highlights" control how flagged layers are marked in the comp viewer.

Fixing a word

Select a misspelled word on the left, review where it appears on the right, then either pick a suggestion and click Replace (fixes every occurrence of that word), click Ignore (skips it for this session and saves it to ignoredWords.txt), or click + Dictionary to whitelist it permanently.

Dictionary files

Drop category word lists (one word per line, or wrong -> right correction lines) into the extension's Dictionary folder for full coverage beyond the built-in fallback list. Use Verify Dictionary to see what's currently loaded.
